# Ludo Friends Android build

Package: `com.ludofriends.game`
Version: `3.2.15` (`versionCode 30`)
Minimum Android: API 23 (Android 6.0)
Target/compile SDK: 36

Open the **project root folder** in Android Studio, allow Gradle sync to finish, then use **Run** to test.

For a signed APK: **Build > Generate Signed App Bundle or APK > APK > release**. Keep the signing keystore and passwords permanently; all future Ludo Friends updates must be signed with the same key.
